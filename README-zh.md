\\\ash
# 克隆项目
git clone https://github.com/yourname/ai-browser-bridge.git
cd ai-browser-bridge

# 安装依赖
npm install

# 一键启动
./启动.bat

## ✨ 功能特性

| 功能 | 描述 |
|------|------|
| 🌐 **浏览器导航** | 访问任意网页 |
| 📸 **截图** | 自动截图页面 |
| 🖱️ **点击/输入** | 模拟鼠标键盘操作 |
| 📋 **获取内容** | 提取页面文本和数据 |
| 🔍 **快照分析** | AI 分析页面内容 |

## 🔧 支持的 AI 工具

- **Cursor** - 代码编辑器内置 MCP
- **Claude Desktop** - Anthropic 桌面应用
- **Codex CLI** - OpenAI 终端工具
- **任意 MCP 客户端** - 标准 MCP 协议
