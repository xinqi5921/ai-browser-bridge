## ✨ Features

| Feature | Description |
|---------|-------------|
| 🌐 **Navigate** | Visit any webpage |
| 📸 **Screenshot** | Auto-capture page screenshots |
| 🖱️ **Click/Type** | Simulate mouse and keyboard |
| 📋 **Extract Content** | Get page text and data |
| 🔍 **Snapshot Analysis** | AI-powered page analysis |

## 🔧 Supported AI Tools

- **Cursor** - Code editor with built-in MCP
- **Claude Desktop** - Anthropic desktop app
- **Codex CLI** - OpenAI terminal tool
- **Any MCP Client** - Standard MCP protocol
