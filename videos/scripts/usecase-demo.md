# 使用案例演示脚本

## 案例 1：自动化表单填写

### 需求
自动填写并提提交登录表单

### 命令
\`\`\`
1. 访问 https://example.com/login
2. 在用户名框输入 admin
3. 在密码框输入 password123
4. 点击登录按钮
5. 截图确认登录成功
\`\`\`

### 预期结果
- 成功填写表单
- 页面跳转到 Dashboard
- 截图保存成功

## 案例 3：批量截图

### 需求
对 10 个网站进行截图

### 命令
\`\`\`
1. 访问 list.txt 中的每个 URL
2. 每个页面等待 3 秒加载完成
3. 截图保存到 screenshots/ 目录
4. 生成报告
\`\`\`
